🏷️ Symbol Badges & Metrics Reference

CRITICAL
Critical Hotspot Risk Tier: High blast radius or severe complexity (cyclomatic $v(G) \ge 15$, cognitive $Cog \ge 25$, monolithic $>100\text{L}$, or cyclic breach). High priority for code review and refactoring.
HIGH / MED
Elevated / Moderate Risk Tiers: Moderate blast radius ($C_a \ge 2$) or elevated branching ($v(G) \ge 4$).
🔀 v135
McCabe Cyclomatic Complexity $v(G)$: Number of linearly independent execution paths through the function (`if`, `for`, `while`, `case`, `&&`, `||`, `?`). v135 means 135 decision branches. (Not a version number!) $\ge 10$ is complex; $\ge 15$ is high risk.
💥 2
Direct Inbound Callers ($C_a$): The blast radius — 2 other functions or methods in the codebase directly call this symbol. If this symbol changes, these 2 call sites are directly impacted.
🚨 3
Architectural Layer Inversions / Breaches: Outbound calls made upward into higher architectural layers (e.g. Entities invoking Presentation), violating unidirectional layering.
🔄 cycle
Circular Dependency Loop: Symbol participates in a circular recursion or cyclic dependency loop with one or more other symbols.
↳ d5
Deep Control Nesting: Deeply indented code blocks (5 levels of nested `if`/loops). Hard to maintain and debug.
📏 mono
Monolithic Function: Method or function body exceeds 100 lines of code. Prime candidate for extraction.
met cla
Symbol Type: met Method, cla Class, fun Global Function, enu State Enum / Table.
