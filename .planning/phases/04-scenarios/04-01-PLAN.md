Implement interactive scenario simulation traces for 4 core workflows in `~/projects/mail`, complete with step-by-step call stacks, active mutex lock indicators, and state mutation diffs.

3. **Concurrent Multi-Account Switching & Lock Contention**: Simulating parallel goroutines accessing shared state and maps.
4. **SQLite Transaction Integrity & Error Rollback**: Testing atomic transaction handling during batch imports.

## Deliverables
