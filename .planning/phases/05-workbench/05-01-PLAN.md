# Plan 05-01: Interactive Visual Workbench UI

## Goal
Build a state-of-the-art interactive web workbench (`workbench.html`) that visualizes the mental model of `~/projects/mail`, featuring interactive graph topology, multi-lens inspection, step-by-step scenario playback, synchronized source code inspector, and Go concurrency explainers.

## Components
1. **Interactive Graph Canvas**: SVG/Canvas node-link network with pan/zoom, physics clustering, and lens-specific highlighting.
2. **Lens Controller**: 5 distinct inspection lenses (Full-Stack, Concurrency, Security, Bridge, Storage).
3. **Scenario Stepper HUD**: Playback sequencer with live call stack, mutex states, and hazard banners.
4. **Code & Refresher Inspector**: Split-pane syntax viewer and Go memory model idiom cards.
5. **Executive Audit Dashboard**: Cognitive architecture summary and invariant pass/fail scorecard.

## Verification
- Load workbench in browser via DevTools / browser tool.
- Verify node clicks, lens toggles, scenario playback stepping, and code inspection.
