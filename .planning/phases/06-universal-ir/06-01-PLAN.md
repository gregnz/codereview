# Plan 06-01: Universal Cognitive Schema (IR) & Polyglot Adapter Framework

## Goal
Formalize the Universal Cognitive Schema (IR) standard, adapter interface contracts, and polyglot fixture datasets (.NET + Oracle, Java + PostgreSQL, Python + SQLite) so any language analyzer can feed the visual verification workbench.

## Tasks

### Task 1: Formal Schema Definition
- Author `schema/universal-ir.json` (JSON Schema Draft 7/2020-12) specifying:
  - Modules, Subsystems, Risk Scores
  - Structs/Classes, Fields, Concurrency Primitives
  - Functions/Methods, Signatures, AST Call trees
  - Concurrency Hazards & Memory Model Explainers
  - Security Taint Flows & Sanitizer Audits
  - Cross-boundary Bridge Endpoints & Invariants
- Author `schema/types.ts` with complete TypeScript interfaces.

### Task 2: CLI Adapter Interface & Protocol
- Implement standard adapter runner allowing external analyzer commands:
  - `codereview --adapter "dotnet run --project /path/to/DotNetAnalyzer"`
  - `codereview --adapter "python -m py_analyzer"`
  - `codereview --import fixtures/dotnet_oracle.json`

### Task 3: Polyglot Reference Fixtures
- Generate rich, realistic reference fixtures in `fixtures/`:
  1. `fixtures/dotnet_oracle.json`: ASP.NET Core billing API, ODP.NET connection pool, Oracle LOB leaks, Sync-over-Async deadlocks.
  2. `fixtures/java_postgres.json`: Spring Boot JPA service, HikariCP, N+1 query traps, `@Transactional` proxy bypass hazards.
  3. `fixtures/python_sqlite.json`: FastAPI task processor, SQLite WAL mode, async event loop blocking hazards.

### Task 4: Workbench Multi-Target Project Switcher
- Enhance `template.html` / `workbench.html` with a **Project Target Selector** dropdown in the top navigation bar, allowing instant switching between Go/Wails, .NET/Oracle, Java/Postgres, and Python/SQLite workspaces with live visual rendering.

## Verification
- Validate all fixture JSONs against `schema/universal-ir.json`.
- Test workbench with each polyglot fixture to verify interactive graph layout, scenario stepping, hazard modal, and idiom explainers.
